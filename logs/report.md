## Почему Latest-2 получил 267 твитов?

### Критическая проблема: Недетерминированность X API

**Факт:** Одинаковые запросы в разницей **несколько секунд** дали совершенно разные результаты:

- Latest-1: 80 твитов (5 страниц)
- Latest-2: 267 твитов (15 страниц)

Это **не нормально** для любого API. Данные должны быть детерминированными для одинаковых параметров.

### Возможные причины проблемы:

#### 1. **"Latest" != хронологический порядок**

- Возможно, "Latest" означает не "последние по времени", а "самые релевантные по алгоритму X"
- Алгоритм может ранжировать твиты по engagement, а не по дате публикации

#### 2. **Встроенные временные ограничения**

- "Latest" может иметь ограничение на временное окно (например, только последние 7-30 дней)
- В разные моменты времени это окно может содержать разное количество твитов

#### 3. **Нестабильность пагинации**

- API может пропускать данные при переходе между страницами
- Курсоры могут быть нестабильными

#### 4. **Кэширование на стороне API**

- Разные результаты из-за разных кэшей или серверов

### Технический анализ:

**Latest-1:**
